# 用户工作流与对话口令

用户说其中任意一句即可；细节（选集、材料正文、草稿批次等）由 Bot 追问补齐。

## 日常学习

| 口令 | 含义 |
|---|---|
| 今日复习 | 选卡片集，做到期练习 |
| 今日总览 | 看今天复习和理解练习还剩多少（可分列概括对照 / 理解问答 / 讲解追问） |
| 结束 | 主动停掉当前复习场（SESSION_ABORTED） |
| 继续 | 接着练已到点的题目 |

## 卡片与材料

| 口令 | 含义 |
|---|---|
| 新建卡片集 | 建一个主题合集 |
| 卡片集列表 | 看各集还剩几题 / 共几题（还剩 x/全部） |
| 新建卡片 | 把一段原始输入放进某个卡片集（原料入库；不是直接建问答卡） |
| 生成练习草稿 | 根据卡片内容出题（先不进复习） |
| 发布练习 | 确认草稿，放进可复习队列 |

## 加深理解（不占日常间隔表）

导航大类称 **理解练习**（非用户口令）。用户直接说下列三条之一：

| 口令 | 含义 |
|---|---|
| 概括对照 | 先用自己的话概括，再对照参考摘要（原「摘要」） |
| 理解问答 | 做开放题，先写再对照（原「开放题」） |
| 讲解追问 | 自己讲清楚，再被追问、修订；不从今日复习自动进入（原「费曼」） |

## 管理

| 口令 | 含义 |
|---|---|
| 暂停卡片 / 恢复卡片 | 无限期移出或重新进入复习队列 |
| 设置保留率 | 调整 FSRS 目标保留率 |
| 备份 / 恢复备份 | 导出或恢复学习数据 |

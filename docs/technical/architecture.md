# 角色、组件与服务

| 名称 | 类型 | 职责 | 不负责 |
|---|---|---|---|
| 用户 | 角色 | 输入材料、审核问答卡、主动作答、选择复习评分；按需发起或安排费曼解释 | 不需要手动计算问答卡复习日期，也不必在每次复习后完成费曼解释 |
| 内容管理组件 | 组件 | 管理卡片集、内容卡片、标签、来源和版本 | 不生成问答卡或计算复习间隔 |
| 材料生成组件 | 组件 | 组织生成请求、校验 Grok Bot 返回结果并管理草稿审核 | 不直接决定用户是否掌握知识 |
| 问答卡复习组件 | 组件 | 管理主动回想、答案揭示、用户评分和今日复习会话 | 不自行计算 FSRS 间隔 |
| 深度练习组件 | 组件 | 管理费曼解释、开放题、摘要重写和独立练习计划 | 不自动占用问答卡复习队列 |
| 学习规则组件 | 组件 | 为 Grok Bot 服务提供固定生成结构、问题质量标准、评价边界和费曼对话规则 | 不保存长期学习状态 |
| Grok Bot 服务 | 服务 | 提取概念、生成题目、评价回答、追问费曼解释、生成薄弱点草稿 | 不直接修改复习间隔，不替用户选择评分 |
| FSRS 服务 | 服务 | 根据问答卡状态、复习时间和用户评分计算下一次复习 | 不评价答案内容 |
| 数据库服务 | 服务 | 保存阅读输入、问答卡、复习状态、日志、对话和配置 | 不执行生成和调度逻辑 |
| 通知服务 | 服务 | 分别查询有效且到期的问答卡与用户已安排的深度练习并提醒（产品能力）；**MVP 默认关闭 learning 短间隔推送** | 不提醒失效、作废或暂停的问答卡，不自动启动费曼练习，不代替实际学习；到点提醒为可选例程 |

术语约定：本文中的“卡片”如无前缀，指承载阅读输入的“内容卡片”；用于主动回想和 FSRS 的学习题目统一称为“问答卡”。内部实体名仍可使用 ContentCard / ReviewCard 等；**面向用户**时优先使用[对话口令](../product/user-workflows.md)。

- **用户口令「新建卡片」**：把一段原始输入放进某个卡片集，成为内容卡片（原料入库）。**不等于**直接创建可复习的问答卡。
- **流水线**：新建卡片（录入）→ 生成练习草稿 → 发布练习。未发布的问答卡不进入今日复习。
学习规则组件由项目内的 [active-reading-learning-rules Skill](../../skills/active-reading-learning-rules/SKILL.md) 实现。

## Anki 机制映射

| Anki 概念 | 本产品对应设计 |
|---|---|
| Deck / Subdeck | CardSet：组织任意阅读输入，不限定为书籍和章节 |
| Note | KnowledgeNote：从内容卡片提取的一个概念或论点 |
| Card | ReviewCard：针对概念生成的问答式或选择题 |
| New / Learning / Review / Relearn | ReviewState 中的问答卡学习状态 |
| Show Answer | 用户提交回答后才揭示参考答案 |
| Again / Hard / Good / Easy | 忘记 / 困难 / 良好 / 容易，由用户选择 |
| Bury Siblings | 同源问答卡暂缓，避免答案互相提示 |
| Suspend | 暂停问答卡，直到用户恢复 |
| FSRS | 依据真实复习时间和用户评分计算下次复习 |
| Statistics | 记忆统计；本产品另加独立的理解练习统计 |

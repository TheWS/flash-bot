# 角色、组件与服务

| 名称 | 类型 | 职责 | 不负责 / MVP 现状 |
|---|---|---|---|
| 用户 | 角色 | 输入材料、审核问答卡、主动作答、选择复习评分；按需发起讲解追问 / 概括对照 / 理解问答 | 不需要手动计算问答卡复习日期，也不必在每次复习后完成讲解追问 |
| 内容管理组件 | 组件 | 管理卡片集、内容卡片（MVP：`title`+`body`）、标签 | 不生成问答卡或计算复习间隔；完整来源/失效字段为**目标扩展** |
| 材料生成组件 | 组件 | 组织生成请求、校验返回结果并管理草稿审核 | MVP 默认可发式 `manage.py generate`；LLM 靠 `draft-import` |
| 问答卡复习组件 | 组件 | 管理主动回想、答案揭示、用户评分和今日复习会话 | 不自行计算 FSRS 间隔；reveal 评测为轻量规则（写入 `eval_note`），不自动评分 |
| 理解练习组件 | 组件 | 管理讲解追问、理解问答、概括对照 | 不自动占用问答卡复习队列；无独立排期表（MVP 简化） |
| 学习规则组件 | 组件 | 为生成/评价提供固定结构与质量标准（Skill 契约） | 不保存长期学习状态；实现侧多为 stub，契约供 Flash/LLM 增强 |
| 生成与评价增强 | 服务（可选） | 提取概念、生成题目、评价回答、讲解追问、薄弱点草稿 | **MVP 未接完整 Grok 评阅**；不直接修改复习间隔，不替用户选择评分 |
| FSRS 服务 | 服务 | 根据问答卡状态、复习时间和用户评分计算下一次复习 | 不评价答案内容；状态在 `review_cards` |
| 数据库服务 | 服务 | SQLite 保存卡片、复习、开放题、摘要、讲解追问会话（feynman_*）、审计与配置 | 不执行生成和调度逻辑 |
| 通知服务 | 服务（产品能力） | 提醒到期问答卡与已安排理解练习 | **MVP 未实现**；默认不推送 |

术语约定：本文中的“卡片”如无前缀，指承载阅读输入的“内容卡片”；用于主动回想和 FSRS 的学习题目统一称为“问答卡”。内部实体名仍可使用 ContentCard / ReviewCard 等；**面向用户**时优先使用[对话口令](../product/user-workflows.md)。

- **用户口令「新建卡片」**：把一段原始输入放进某个卡片集，成为内容卡片（原料入库）。**不等于**直接创建可复习的问答卡。
- **流水线**：新建卡片（录入）→ 生成练习草稿 → 发布练习。未发布的问答卡不进入今日复习。
- **理解练习**（导航大类，非口令）：概括对照、理解问答、讲解追问三条用户口令。

学习规则组件由项目内的 [active-reading-learning-rules Skill](../../skills/active-reading-learning-rules/SKILL.md) 描述契约；运行时实现以 `<APP_HOME>/` CLI 为准。

## Anki 机制映射

| Anki 概念 | 本产品对应设计 |
|---|---|
| Deck / Subdeck | CardSet：组织任意阅读输入，不限定为书籍和章节 |
| Note | KnowledgeNote：从内容卡片提取的一个概念或论点 |
| Card | ReviewCard：针对概念生成的问答式或选择题 |
| New / Learning / Review / Relearn | `review_cards.state` 中的问答卡学习状态 |
| Show Answer | 用户提交回答后才揭示参考答案 |
| Again / Hard / Good / Easy | 忘记 / 困难 / 良好 / 容易，由用户选择 |
| Bury Siblings | 同源问答卡暂缓（目标能力；MVP 可简化） |
| Suspend | 暂停问答卡，直到用户恢复 |
| FSRS | 依据真实复习时间和用户评分计算下次复习 |
| Statistics | 记忆统计；理解练习统计为**目标**，MVP 未做独立面板 |
